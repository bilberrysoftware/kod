# Welcome to kod

kod is the Kubernetes Offline Deployment tool.

kod makes it easy to take public 
[helm charts](https://helm.sh) 
and their container images and move them as a single archive
to a private registry for installation into an air-gapped Kubernetes instance. 
kod also supports the packaging of [helmfile](https://helmfile.readthedocs.io/)
definitions to enable the packaging and ordered installation of a set of Helm charts to different namespaces.
